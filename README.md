# 收文件 Checklist

一个单文件（`checklist.html`）的收文件核对清单工具，零依赖、无需构建，浏览器打开即用。数据保存在浏览器 IndexedDB 中，可通过 JSON 导入导出备份。

## 功能特性

- **预设任务**：内置成都市卫生健康系统直属单位与区市县共 43 个单位的核对清单，按「直属单位 / 区市县」分组展示
- **自由任务**：🔓 标记，单位名称不预设，可按需逐个添加/删除，单列表展示
- **状态管理**：已收、已反馈、未交、不需要 四种状态一键切换，行底色随状态着色
- **收多个模式**：自定义多个接收标签（最多 5 个），按标签分别标记收取情况
- **备注**：双击单元格即可编辑各单位备注
- **更新时间**：自动记录每次状态变更时间
- **批量操作**：整组一键设为「不需要」
- **任务管理**：新建、重命名、归档、删除多个任务，左侧卡片快速切换
- **导入导出**：全部任务数据以 JSON 导出 / 导入，便于备份与迁移
- **深色模式**：支持浅色/深色主题切换，自动跟随系统偏好

## 使用方法

直接用浏览器打开 `checklist.html` 即可，无需安装任何依赖。

## 数据说明

- 数据存储于浏览器 IndexedDB（库名 `DocChecklistDB`），仅本地保存
- 建议定期使用「导出数据」备份，防止清除浏览器数据导致丢失
- 「导入数据」可将备份恢复；导入时会自动兼容旧格式数据

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `checklist.html` | 应用本体（HTML + CSS + JS 单文件） |
| `names.json` | 单位名称数据源 |
| `checklist.xlsx` | 单位名单表格（对照参考） |
